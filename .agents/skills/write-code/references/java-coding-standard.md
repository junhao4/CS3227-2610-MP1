# Java coding standard

Read the applicable rules in the [SE-EDU Java coding standard](https://se-education.org/guides/conventions/java/).

Follow existing project conventions. In particular, use clear English names,
explicit imports, braces, 4-space indentation, lines no longer than 120
characters, and concise Javadocs for public APIs and non-trivial private
methods. Explain WHAT or important WHY, not line-by-line HOW.
